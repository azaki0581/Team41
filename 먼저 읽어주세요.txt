 ▶  들어있는 파일
 ─────────────────────────────────────────────────────────────────────

      index.html  ······  앱 전체 (화면 + 추천 로직)

      recipes.js  ······  레시피 1,151건

      tools/      ······  recipes.js 를 만드는 스크립트

 ▶  같이 작업할 때
 ─────────────────────────────────────────────────────────────────────

      무엇을 바꾸려면               어느 파일을 고치나
      ───────────────────────────────────────────────────────────

      화면 · 문구 · 디자인          index.html

      재료 이름 통일                tools/rules.json
      양념 목록                     ↳ 고친 뒤 아래 명령 실행
      조리시간 기준                    .\tools\build-recipes.ps1


      서로 다른 파일이라 동시에 작업해도 충돌하지 않습니다.

      tools/rules.json 은 항목마다 밑줄(_)로 시작하는 설명이 붙어 있어서
      파일만 열어봐도 무엇을 고치면 되는지 알 수 있습니다.



 ▶  꼭 지켜주세요
 ─────────────────────────────────────────────────────────────────────

      1.  recipes.js 를 직접 고치지 마세요.

          tools/rules.json 을 고치고 build-recipes.ps1 을 다시 돌리면
          알아서 새로 만들어집니다.
          직접 고치면 다음 실행 때 덮어써집니다.


      2.  tools 안의 .ps1 파일은  UTF-8 BOM  으로 저장하세요.

          Windows PowerShell 은 BOM 없는 파일을 ANSI 로 읽기 때문에
          한글 주석이 전부 깨집니다.
          VS Code 기준 : 오른쪽 아래 인코딩 → UTF-8 with BOM



 ▶  아직 완성본이 아닙니다
 ─────────────────────────────────────────────────────────────────────

      남은 작업과 알려진 한계는
      README.md 의 8번 · 9번 항목에 정리해두었습니다.
